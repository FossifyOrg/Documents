Fossify Documents 是一款注重隱私、簡潔的離線文件檢視與管理工具，開啟 PDF、DOCX、文字文件、Markdown、CSV、TSV 和 HTML 檔案，並將它們置於隨手可及之處，沒有廣告、追蹤或網路連線權限。<br><br>

<b>📄 輕鬆讀取文件</b><br>
• 開啟 PDF、DOCX、純文字、Markdown、CSV、TSV 和 HTML 文件<br>
• PDF 頁面切換，放大或縮小，以完整全螢幕模式檢視<br>
• 開啟受密碼保護的 PDF<br>
• 以適合行動裝置的簡潔版面讀取 DOCX 檔案<br>
• 以專屬表格檢視 CSV 和 TSV 檔案<br>
• 安全地離線檢視 HTML 文件<br>
• 預覽具有標題、清單、表格、連結、程式碼等內容的格式化 Markdown<br>
• 列印 PDF 或以其他相容應用程式開啟文件<br><br>

<b>✍️ 建立與編輯</b><br>
• 在 Android 支援的任何位置建立純文字和 Markdown 文件<br>
• 編輯現有純文字和 Markdown 文件<br>
• 以純文字編輯 CSV 和 TSV 檔案，保留用於閱覽的表格檢視<br>
• 使用便利的 Markdown 格式控制編修標題、粗體、斜體、引用資料、清單和程式碼<br>
• 編輯時查看詞數和字元數<br><br>

<b>📁 保持井然有序</b><br>
• 直接於應用程式內新增資料夾並瀏覽支援格式文件<br>
• 快速返回最近開啟文件<br>
• 將重要文件標記為最愛<br>
• 搜尋、篩選，依據名稱、日期或檔案大小排序<br>
• 切換合適的清單和格狀檢視模式<br><br>

<b>🔒 注重隱私的設計</b><br>
Fossify Documents 完全離線運作，不需要任何網際網路權限，您的文件將存放於個人裝置或指定位置，沒有任何廣告、資料分析或追蹤。<br><br>

<b>🎨 為您量身訂作</b><br>
透過 Fossify 主題、色彩、圖示和字體自訂應用程式外觀，完整支援淺色與深色模式，創造融入您裝置特色的文書體驗。<br><br>

<b>簡單。隱私。您做主</b><br><br>
